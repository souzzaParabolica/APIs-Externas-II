# 6️⃣ Estatísticas de Jogos Esportivos — BALLDONTLIE

Projeto acadêmico para coletar e analisar estatísticas de jogadores da NBA usando uma API.

## Objetivos

- Consumir uma API esportiva com `requests`;
- Trabalhar com listas de objetos JSON;
- Transformar os dados em `pandas.DataFrame`;
- Calcular médias de pontos, rebotes e assistências;
- Criar rankings;
- Comparar dois jogadores em gráfico lado a lado;
- Gerar um ranking dos 10 jogadores com maior média de pontos;
- Utilizar `seaborn` para visualização;
- Manter a chave da API fora do GitHub usando `.env`.

## Tecnologias

- Python 3.10+
- requests
- pandas
- seaborn
- matplotlib
- python-dotenv
- API BALLDONTLIE NBA

A documentação oficial informa que a API requer uma chave de API e disponibiliza endpoints de jogadores e estatísticas.
